Search, replace, and filter commands help move through large sheets, change matching text, or visually reduce the document to cells that match a search, edit time, note, or color condition.

Search, replace, and filters

Code verified

Search uses the toolbar search field and can be case-sensitive or case-insensitive. Next and Previous jump through matching cells. Replace can change the current selection, replace and jump to the next match, or replace all matches. Filters visually reduce the sheet to cells that match current search text, edit time ranges, notes, or a selected background color.

  • Replace requires a search string. Search and filter commands work across the document hierarchy, not only the currently visible cells.
  • Search jumps select the matching cell and may zoom in if the match is too small to read. Replace is undoable. Filters keep matching cells readable while reducing non-matching cells visually.
  • If no search string exists, next/previous can seed the search field from the currently selected cell text; otherwise they report that one cell must be selected or no text exists.

On Windows, Enter in the search/replace text controls is emulated in OnMenu because EVT_TEXT_ENTER is not generated.
