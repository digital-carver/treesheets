Layout and View

Zooming, text size, column width, render styles, presentation scaling, scrolling, and view-related options.

Updated last on 2026-05-09 · Source commit 84ef9b924c79
Machine-assisted reference docs. Reliability indicators and footnote citations are included with every section.

TreeSheets layout is meant to keep large nested sheets compact while letting you zoom into the part you want to read or edit. Layout commands change how selected cells and grids occupy screen space; view commands change what portion of the sheet you are looking at.

Text style, sizing, colors, and borders

Code verified

Style commands toggle bold, italic, typewriter, underline, and strikethrough styling on selected cells. Text-size commands make selected content more or less prominent. Column-width commands change wrapping width, which is useful for long text. Border-width and color commands change how selected grids and cells are drawn.

  • These commands require a selected grid. Style and reset commands iterate selected cells, while border width acts on the selected grid itself.
  • These changes are undoable and TreeSheets recalculates layout after they are applied.
  • Reset colors treats tag cells specially by resetting the stored tag color, while normal cells reset text, cell, and nested-grid border colors.

The border menu labels are numbered 0 through 5, but the visible result is a set of progressively wider grid borders rather than a literal zero-width-to-five-width scale.

Layout direction and render styles

Code verified

Layout commands change whether cell text and child grids are arranged vertically or horizontally, and whether grids are drawn in grid, bubble-hierarchy, or line styles. Render-style-only commands preserve the current orientation while changing the drawing style.

  • The selected grid must not be a thin selection. Render-style-only commands set the containing grid draw style when the whole grid is selected.
  • The changes are undoable and TreeSheets redraws the affected layout.
  • Thin selections are rejected with the normal no-thin-selection message.

Shortcut labels deliberately use Ctrl on macOS and Alt elsewhere.

Zoom, scroll, tabs, fullscreen, and scaled presentation view

Code verified

Zoom moves the view into or out of nested grids, making deeply nested or tiny text readable without permanently changing the sheet. Scrolling moves the canvas when the current layout is larger than the window. Fullscreen hides normal window chrome; scaled presentation view fits the sheet to the available screen area for presentation-style viewing.

  • Zooming in needs a selected cell or grid context. Zooming out can return toward the root view. Tab commands cycle between open TreeSheets documents.
  • TreeSheets keeps a view path for the zoomed-in cell and redraws the current view. Scaled presentation view computes a screen-fitting scale between normal size and a capped enlarged view, then restores normal rendering when toggled off.
  • When a command jumps to a cell inside a folded grid, TreeSheets may unfold ancestors or zoom out enough to make the selection visible.

F12 is described historically as useful for presentations. It changes how the current view is drawn; it is not a slide deck mode.
