Selection and Navigation

Selection shapes, movement, expansion, parent/child traversal, and matching-cell jumps.

Updated last on 2026-05-07 · Source commit a6d64cacc924

TreeSheets uses one selection model for cells, grid lines, and text cursors. Many commands first expand thin grid-line selections or single-cell selections before acting.

Move, extend, and move cells

Implementation verified

Menu entries, keyboard fallback, and selection cursor implementation were traced.

CommandMenu PathShortcutID / Handler
Move selectionEdit > SelectionArrow keysA_LEFT/A_RIGHT/A_UP/A_DOWN
Move cellsEdit > SelectionCtrl+ArrowA_MLEFT/A_MRIGHT/A_MUP/A_MDOWN
Extend selectionEdit > SelectionShift+Arrow, Ctrl+Shift+ArrowA_SLEFT/A_SRIGHT/A_SUP/A_SDOWN/A_SC*

Behavior

Arrow commands move the selection or text cursor. Ctrl+Arrow moves selected cells around the grid outside text edit mode; in text edit mode horizontal Ctrl movement jumps by word-like runs. Shift extends the rectangular grid selection or the text selection.

Context

Movement acts on the active grid selection. Text edit mode changes the same command IDs into cursor and text-selection actions.

Effects

Cell movement records undo, calls Grid::Move, wraps coordinates through grid bounds, resets affected children, and scrolls to the new selection. Shift expansion changes the selection rectangle while clamping to grid bounds.

Edge Cases

On GTK, several accelerators are emulated in Document::Key because wxGTK does not support those keycodes as menu accelerators.

Quirks

Ctrl+I can arrive as Ctrl+Tab on Linux, so Ctrl+Tab tab switching is intentionally ignored there and Ctrl+Shift+Tab remains the reliable previous-tab shortcut.

Select all, parent, and first child

Implementation verified

Menu entries and command branches were traced to Selection and Document implementations.

CommandMenu PathShortcutID / Handler
Select all in current grid/cellEdit > Selection > Select all in current grid/cellCtrl+AwxID_SELECTALL
Select Parent / Cancel text editsEdit > Selection > Select Parent; Edit > Text Editing > Cancel text editsEscA_CANCELEDIT
Select First Child / Insert New GridEdit > Selection > Select First Child; Edit > Insert New GridShift+Enter / InsA_ENTERGRID

Behavior

Select all selects every cell in the current grid, or all text in the current cell when already in text edit mode. Esc exits text edit mode; outside text edit mode it selects the parent cell, or the entire root grid if there is no parent. Entering a child grid selects the first cell of an existing subgrid, or creates a new 1x1 subgrid when none exists.

Context

Select all requires a current grid. Parent traversal needs a grid selection; child traversal requires a single expandable cell.

Effects

Selection coordinates are rewritten to the target grid or parent cell. Creating a subgrid records undo, creates the grid, selects its first cell, and refreshes the canvas.

Edge Cases

Esc in text edit mode may undo coalesced text entry before leaving edit mode. Creating an NxN grid prompts for size and can be cancelled.

Quirks

A_ENTERGRID is exposed in two contexts: as child selection when a child grid exists, and as grid creation when the selected cell has none.
