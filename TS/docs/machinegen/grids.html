Grids and Hierarchies

Subgrid creation, folding, hierarchy operations, sorting, transposition, hierarchify, and flattening.

Updated last on 2026-05-09 · Source commit 84ef9b924c79
Machine-assisted reference docs. Reliability indicators and footnote citations are included with every section.

Grids are nested inside cells. Many structural commands either operate on the selected grid or on subgrids inside the selected cells.

Create, fold, wrap, transpose, flatten, and hierarchify grids

Code verified

Grid creation adds a subgrid to one selected cell or enters an existing subgrid. Wrap creates a new parent hierarchy around the current selection. Folding hides or shows subgrids inside selected cells. Transpose changes grid orientation, Hierarchify converts repeated table values into hierarchy, and Flatten converts nested hierarchy into a flat grid for export or spreadsheet-style work.

  • Creation needs one expandable cell. Transpose rejects thin selections. Hierarchify requires a selected cell or whole grid with a table-like grid. Flatten requires a grid and can operate on the selected cell or all selected grid.
  • Structural changes are undoable. TreeSheets refreshes layout and updates the selection to the affected grid or cell where appropriate.
  • The root grid cannot be removed by grid deletion. Hierarchify refuses grids whose cells already contain subgrids.

Fold state is saved in TreeSheets XML, so folded grids remain folded when the structure is exported and reimported.

Hierarchy Swap

Code verified

Hierarchy Swap promotes cells with the same text as the selected cell upward within the selected cell's grandparent scope. It is useful when a hierarchy has the right information but is organized around the wrong level, such as wanting people grouped above projects instead of inside projects.

  • The selected cell must have both a parent and a grandparent, and both the parent and grandparent grids must be one-dimensional: either 1xN or Nx1.
  • Matching cells are promoted, their ancestor chain is nested under the promoted cell, duplicate promoted tags are merged, empty one-cell shells are pruned, and the command remains undoable as one operation.
  • Matching is exact and case-sensitive. A very deep match may need repeated swaps because each keypress works from the selected cell's grandparent grid.

Hierarchy Swap can restructure multiple matching branches in one keypress. Preview the structure mentally or keep undo close when using it on large sheets.
