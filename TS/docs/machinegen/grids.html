Grids and Layout

Subgrid creation, folding, hierarchy operations, layout direction, render styles, and flattening.

Grids are nested inside cells. Many structural commands either operate on the selected grid or on subgrids inside the selected cells.

Create, fold, wrap, transpose, flatten, and hierarchify grids

Behavior

Grid creation adds a subgrid to one selected cell or enters an existing one. Wrap creates a new parent hierarchy around the selection. Folding toggles whether selected subgrids are displayed. Transpose changes grid orientation, Hierarchify converts a table-like grid into hierarchy, and Flatten converts nested hierarchy into a flat grid sized by depth and leaves.

Context

Creation needs one expandable cell. Transpose rejects thin selections. Hierarchify requires a selected cell or whole grid with a table-like grid. Flatten requires a grid and can operate on the selected cell or all selected grid.

Effects

Structural commands add undo, mutate grid ownership or layout, reset child layout caches, rewrite selection, and refresh the canvas.

Edge Cases

Root-grid deletion is guarded in Grid::DelSelf. Hierarchify refuses grids whose cells already contain subgrids.

Quirks

Fold stores a boolean on Grid and export serialization includes a folded attribute for XML output.

Toggle vertical layoutEdit > Layout & Render StyleAlt+0 on non-macOS, Ctrl+0 on macOSA_TEXTGRID

Behavior

Layout commands set selected cells or selected grids to vertical/horizontal text-and-grid layout and grid, bubble-hierarchy, or line render styles. Render-style-only commands preserve orientation while changing draw style.

Context

The selected grid must not be a thin selection. Render-style-only commands set the containing grid draw style when the whole grid is selected.

Effects

Commands add undo, call SetGridTextLayout, reset children, and refresh the canvas.

Edge Cases

Thin selections are rejected with the normal no-thin-selection message.

Quirks

Shortcut labels deliberately use Ctrl on macOS and Alt elsewhere.
