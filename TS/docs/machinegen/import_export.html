Import and Export

File import, export formats, clipboard serialization, and image export behavior.

TreeSheets converts the current view or selected content into XML, HTML, text, CSV, bitmap, SVG, and clipboard formats. CSV export has extra flat-grid requirements.

Import and export current views

Implementation verified

Export writes the current view as XML, HTML tables, HTML with images, bullet-list HTML, outline HTML, indented text, CSV, PNG, or SVG. Import can load XML, XML with attributes, indented text, comma/semicolon CSV, and tab-delimited text.

  • Export uses currentdrawroot as the export root and selected view state. Import opens one or more files and initializes a new document from parsed content.
  • Successful import creates or replaces the active document contents, marks it modified, clears selection/drag state, and refreshes. HTML with images writes companion image files.
  • CSV export refuses non-flat grids and suggests zooming to the desired grid or using Flatten. Import failure shows an error message.

XML export can round-trip TreeSheets structure, while CSV export is intentionally limited to flat grids.
