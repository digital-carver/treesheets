Behavior

Program > Run evaluates the root cell through the evaluator, resets children, clears selection, and refreshes. Mark commands assign cell types used by the evaluator; operation cells infer their precise operation type from text. When Lobster is enabled, scripts are loaded into a Script menu and executed from history entries.

Context

Run acts on the document root. Mark commands require an active grid selection. Script menu commands are compiled only when ENABLE_LOBSTER is defined.

Effects

Run records undo on the root, evaluates, resets layouts, clears selection and drag state, and refreshes. Mark commands add undo and change celltype for every selected cell.

Edge Cases

Script history command IDs are separate from tag command IDs and are handled in TSFrame::OnMenu before normal Document::Action dispatch.

Quirks

The generated docs mark script menu behavior as implementation verified but conditional on ENABLE_LOBSTER.
