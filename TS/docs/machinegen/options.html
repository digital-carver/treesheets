Options

Application preferences, rendering toggles, document safety options, and HTML autoexport.

Updated last on 2026-05-09 · Source commit 84ef9b924c79
Machine-assisted reference docs. Reliability indicators and footnote citations are included with every section.

Options mostly change persistent application behavior: fonts, colors, toolbar visibility, file safety features, cursor navigation, mouse-wheel behavior, dark-mode rendering, and automatic HTML export.

Application options and persistent preferences

Menu declared

Options let you customize fonts, language, key bindings, default column width, background and cursor colors, toolbar/statusbar visibility, tab placement, tray behavior, startup minimization, mouse-wheel behavior, cursor navigation between cells, backup/autosave/autoreload behavior, document centering, line rendering, dark-mode inversion, and grid-border roundness.

  • Most checkable options are persistent preferences. Dialog-based options, such as font selection, language, key bindings, and default column width, prompt before changing the stored value.
  • Changing an option usually writes to the application configuration and refreshes the current UI or document view. Some options, such as file watching and autosave, affect later background behavior rather than the current sheet immediately.
  • The option labeled "File Tabs on the bottom" writes the tab-placement preference; the menu text and internal historical name disagree about top/bottom orientation, so the live UI should be checked if this detail matters.

This section deliberately uses a weaker evidence level because it covers many options from declarations and persistence paths without tracing every resulting UI effect.
