Cells, grids, and selections

Code verified

A TreeSheets document is a root cell containing a grid. Cells can hold text, images, notes, and nested grids, so a sheet can behave like a spreadsheet, an outline, a mind map, or a compact personal database depending on how you nest those grids.

  • Most commands act on the current selection. The selection may be a rectangle of cells, a grid line used for insertion or deletion, or a text cursor inside one cell.
  • Selection state determines whether TreeSheets edits text, inserts or deletes rows and columns, enters a child grid, or applies commands to a larger rectangular group.
  • If a command needs a selected grid, a non-thin selection, or exactly one cell and the current selection cannot provide it, TreeSheets reports that requirement instead of changing the document.

The same visible selection system covers rectangular cell selections, grid-line positions, and text cursors. That makes many shortcuts context-sensitive.

Verified from the document model, selection model, file-format notes, and the official tutorial.
