Cells, grids, and selections

Implementation verified

Verified from the Selection class and Grid/Cell model methods.

Behavior

A TreeSheets document is a root cell with an optional grid. A grid owns cells and keeps dimensions, column widths, orientation, border state, and folding state. A selection points at a grid with x/y coordinates and width/height, or uses zero width/height as a thin grid-line selection.

Context

Commands generally require an active selection with a grid. Single-cell commands call GetCell or ThinExpand; whole-grid commands may operate when the selection covers all cells.

Effects

Selection state can enter text edit mode, exit text edit mode, expand to all cells, or be reassigned to a parent or child grid.

Edge Cases

If a command needs a selected grid or one cell and the selection cannot provide it, Document::Action returns user-facing messages such as NoSel, OneCell, NoThin, or NoGrid.

Quirks

The same Selection object represents text cursors, rectangular cell selections, and thin grid-line insertion/deletion targets.
