Editing Cells

Text editing, clipboard operations, deletion, notes, images, styles, and sizing.

Updated last on 2026-05-09 · Source commit 84ef9b924c79
Machine-assisted reference docs. Reliability indicators and footnote citations are included with every section.

Editing commands often branch on whether the current selection is a grid selection, a thin grid-line selection, or text edit mode inside one cell.

Clipboard, delete, and collapse

Code verified

Cut and copy place the current text, image, or cell selection on the clipboard. Paste can restore TreeSheets cell data, insert plain text, create grids from multi-line text, accept image data, or paste a dropped file path or image. Delete and Backspace either edit text, remove cells, or remove rows/columns when a grid line is selected. Collapse combines selected cell text into the first selected cell.

  • Clipboard and delete behavior is highly selection-dependent: text edit, thin grid line, one cell, or rectangular grid selection all route differently.
  • Mutating operations are undoable. TreeSheets refreshes the layout after deleting or pasting, and may zoom out if the selected grid disappeared.
  • Delete at the end of text and Backspace at the beginning of text are no-ops. Collapse requires more than one selected cell and some content to collapse.

Pasting a TreeSheets file path asks whether to open the file, paste the path, or cancel. Multi-line text paste can replace a cell with a grid of rows and then merge with the parent when the original cell has no text.

Images, links, and file launching

Code verified

Image commands add, save, rescale, display-scale, reset, convert, reuse, or remove images in selected cells. Browsing commands open selected cell text as a URL in the default browser or as a file path in the default application.

  • Most image commands require selected cells and act recursively through the selection when collecting images. Browsing iterates selected cells without recursion.
  • Image changes are undoable and TreeSheets refreshes the layout afterward. File browsing resolves relative file paths against the current TreeSheets file path before launching.
  • Saving images reports when the selection has no images. Browsing stops after a configured maximum number of launches and reports failed launches.

Display-only image scaling applies to all uses of the same image object, not only the selected cell.

Notes and tags

Code verified

Notes are extra text attached to a cell and edited through a dialog. Tags are reusable cell-text labels with associated colors; TreeSheets can add the selected cell text as a tag, remove it from the tag list, or apply an existing tag from a popup/menu path. The note filter shows cells that have notes.

  • Editing a note requires one selected cell. Tag operations act on selected cell text and the document's tag list. The note filter scans the document for cells with non-empty notes.
  • Note and tag changes are undoable where they change document content. Notes are saved with cells, copied with cells when appropriate, and can be used as a filter criterion.
  • The tag popup can be reached from Ctrl+right-click according to the menu tooltip; exact pointer behavior is not covered by this generated documentation.

Notes are not the same as visible cell text. A sheet can filter to note-bearing cells even when the note itself is not part of the cell's main visible text.

Text edit mode

Code verified

Text edit mode lets you change the text inside one cell. Press `Enter` to enter or leave text editing, or press `F2` to start editing at the end of the cell text. Typing into a selected cell also begins editing.

  • The command needs one selected cell, or a grid-line selection that can expand into a new neighboring cell. In text edit mode, cursor keys and text-selection shortcuts act inside the cell text instead of moving the grid selection.
  • TreeSheets shows an edit cursor and keeps edits undoable. The progress variants leave the current cell and move to a nearby cell, making spreadsheet-like data entry possible.
  • If the selection cannot be expanded to one cell, the command reports that one cell must be selected.

The labels for Ctrl/Alt Enter are platform-dependent: macOS uses Ctrl for several layout/render shortcuts where other platforms use Alt.
