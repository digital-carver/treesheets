Editing Cells

Text editing, clipboard operations, deletion, notes, images, styles, and sizing.

Updated last on 2026-05-08 · Source commit 261add4e446c
AI-generated reference docs. Reliability indicators and footnote citations are included with every section.

Editing commands often branch on whether the current selection is a grid selection, a thin grid-line selection, or text edit mode inside one cell.

Clipboard, delete, and collapse

Implementation verified

Cut and copy serialize the current selection unless it is a thin grid-line selection; in text edit mode they require a non-empty text range. Paste accepts TreeSheets internal cell clipboard, text, file drops, images, and multi-line text that can create a subgrid. Delete and Backspace either remove rows/columns from thin selections, edit text, or delete selected cell content and potentially compact the grid. Collapse merges selected cell text into the first selected cell and deletes the remaining selected cells.

  • Clipboard and delete behavior is highly selection-dependent: text edit, thin grid line, one cell, or rectangular grid selection all route differently.
  • Mutating operations add undo, clear or modify cells, call MultiCellDelete or text deletion helpers, refresh the canvas, and may zoom out if the current grid disappeared.
  • Delete at the end of text and Backspace at the beginning of text are no-ops. Collapse requires more than one selected cell and some content to collapse.

Pasting a TreeSheets file path asks whether to open the file, paste the path, or cancel. Multi-line text paste can replace a cell with a grid of rows and then merge with the parent when the original cell has no text.

Images, links, and file launching

Implementation verified

Image commands add, save, rescale, display-scale, reset, convert, reuse, or remove images in selected cells. Browsing commands launch selected cell text either as a URL in the default browser or as a file path in the default application.

  • Most image commands require selected cells and act recursively through the selection when collecting images. Browsing iterates selected cells without recursion.
  • Image mutation updates image buffers or display scale, resets layout, and refreshes. File browsing resolves relative file paths against the current TreeSheets file path before launching.
  • Saving images reports when the selection has no images. Browsing stops after a configured maximum number of launches and reports failed launches.

Display-only image scaling applies to all uses of the same image object, not only the selected cell.

Text edit mode

Implementation verified

Text edit mode turns a single cell selection into an insertion cursor or text range. Enter opens edit mode with all text selected by default, F2 opens at the end, and progress variants leave edit mode by moving to a neighboring cell when already editing.

  • The command requires a single selected cell, or a thin selection that can be expanded into a cell. Typing printable characters also enters or creates text content after expanding/wrapping a selection as needed.
  • Entering text edit mode sets the I-beam cursor, cursor positions, paint-scroll flag, and refreshes the canvas. Text keystrokes add undo and insert into the cell text.
  • If the selection cannot be expanded to one cell, the command reports that one cell must be selected.

The labels for Ctrl/Alt Enter are platform-dependent: macOS uses Ctrl for layout/render shortcuts and non-macOS uses Alt in several menu strings.

Text style, sizing, colors, and borders

Implementation verified

Style commands toggle bold, italic, typewriter, underline, and strikethrough styling on the selected cells. Text size and column width commands adjust the selected content or reset it to defaults. Border width commands change the selected grid's border spacing. Last-color commands apply the most recently used cell, text, or border color to the selection.

  • These commands require a selected grid. Style and reset commands iterate selected cells, while border width acts on the selected grid itself.
  • Commands add undo, change style, size, width, or color data, refresh layout, redraw the canvas, and update status where appropriate.
  • Reset colors treats tag cells specially by resetting the stored tag color, while normal cells reset text, cell, and nested-grid border colors.

The border menu labels are numbered 0 through 5, but the visible result is a set of progressively wider grid borders rather than a literal zero-width-to-five-width scale.
